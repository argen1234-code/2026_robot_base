小车 WASD · 两轮差速模式

连接就绪后即可进入键盘控制。进入时接管两轮目标并归零，随后按 WASD 行驶。速度上限、电流和加速度沿用现有设置。

另一台电机自动作为右轮；按实际安装方向选择正反转。W 前进、S 后退、A 左转、D 右转；组合键转弯时内轮归零，外轮按所填轮速运行。

JY901S · 绝对角度 / 双轮速度控制

上电收到首个有效航向后为 0°。从车顶看，正角度向左转，负角度向右转；90° 是左转到上电方向的 90°，0° 回到上电方向，360° 是完整一圈。左右轮及前进方向沿用上方 WASD 设置。

连接时自动应用两台电机的速度上限、电流和加速度，并零速使能。随后可直接指定双轮速度、运行航向 PID，或进入上方 WASD。左右轮速度由电机内部闭环控制。

从连接到第一次转动

QUICK START
01

连接现有硬件

使用当前接好的 CMSIS-DAP / ST-Link。PC → SWD → H743 → CAN → RS05。无需额外串口，也不使用 COM5。

02

运行并释放调试器

在 Keil 中运行匹配固件，退出 Debug。不要同时让 Keil 与上位机占用探针。选择设备并点击连接。

03

连接即就绪

连接时自动识别两台电机、配置速度模式并零速使能。默认速度上限 33 rad/s、相电流 2.4 A、加速度 20 rad/s²；修改限制后重新连接生效。

04

低速验证反馈

设置目标速度（正数正转、负数反转），点击运行。滑块只编辑目标，不立即发出运动命令。一次运行指令持续有效；修改速度后需再次点击应用，无需定时续发。

停止方式

减速停止：按加速度降到零，保持使能。选中电机失能；Esc 两台全部失能：向固件请求失能，需新反馈确认；不能替代断电或机械急停。关闭页面不会停止运动。主动断开连接或退出上位机会请求失能；服务被强制终止或探针突然断开时，H743 中的速度仍可能持续有效，需重新连接后停止或直接断电。本电机拒绝 CAN 超时参数，未验证电机侧断线自停。

当前工程能力

速度控制与位置、力矩、温度、电流、电压观测。位置和力矩仅反馈，不提供对应控制模式。电机掉线、过期或快照不一致时显示无效；CAN ACK 不代表电机已在线或已转动。
