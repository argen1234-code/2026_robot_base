# WS2812 上位机控制（2026-10-26）

工程为 `RobStride05_H743` FreeRTOS 版本，灯带保持 16 颗，PA6/TIM3/DMA 驱动、50 fps。两个 Cache 仍关闭。新版固件已下载；启动文件为 `D:\竞赛\2026 AIC\上位机\RobStrideConsole.exe`。

## 使用

连接设备，点击左侧“灯带控制”。这项操作不需要准备或使能电机。

- 显示方式：流动彩虹、双向彗星、极光波浪、火焰、流动等离子、往返扫描、纯色常亮，或自定义循环。
- 亮度 0–255；动画速度 1–400%。RGB 可通过拾色器或三个数字输入框编辑，作用于扫描与常亮，其余灯效使用自身配色。
- 自定义循环：添加、上移、下移、移除灯效，最多 8 项，支持重复项；“循环全部 7 种”可快速生成列表。每项播放时长为 1–600 秒，可按 0.1 秒调整，与动画速度独立。
- 修改仅留在编辑区，点击“应用到灯带”才发送。界面收到固件回执后提示成功，并比较编辑值与板上实际配置。
- “关闭灯带”发送一帧全黑并停止刷新；勾选开启后应用即可恢复。“读取板上设置”会覆盖当前编辑区。
- “保存到本机”将当前方案存入当前浏览器的本地存储；“读取本机方案”仅填入编辑区，仍需点击应用。更换浏览器、本地服务端口或清除浏览器数据会改变这份存储。

循环在 MCU 上执行，关闭页面或断开上位机后继续播放。MCU 断电/重启恢复默认六种灯效、8 秒间隔、亮度 64/255；没有写入 Flash。上位机主动断开/退出仍沿用原来的双电机失能操作，灯带保留当前程序。

## 实现与验证

- `App/app_led.[ch]`：独立灯效命令区 `g_led_cmd`，奇数序号编辑、完整载荷后提交偶数序号，LED 任务检查整组参数后应用，回执存放在 `g_led`。无效载荷保持原有配置。循环顺序、重复项、实时时长均由 LED 任务执行，不新增任务，不改双电机控制代码。
- 上位机 `profile.py` 从当前 AXF/DWARF 解析灯带状态和命令地址、字段及数组；写入前仍核对完整 Flash。旧固件没有对应灯效命令区时明确显示不支持控制。
- `bridge.py`/`server.py` 与电机共用单一 SWD 工作线程，灯效整组写入并读回校验，再等待固件确认。`web/led.js` 提供页面与本机方案保存。
- Keil 构建 0 errors / 0 warnings；下载与 Flash 校验通过，启动正常，Cache 保持关闭。
- 28 个 Python 测试通过；真实 C LED 服务验证了 16 颗数据、未提交命令忽略、非法配置拒绝、播放顺序/重复项、计时回绕、DMA 忙和错误、关灯与恢复。原双电机和 OLED 主机检查也通过。
- 实板页面检查依次应用全部 7 种灯效，验证 RGB、亮度、动画速度、关灯/恢复，以及 `[7,1,7]` 列表每秒切换、重复项、保存/读取、刷新页面及断开后继续运行。整个过程中两台电机保持失能，灯带发送无错误；正常与窄屏页面已截图复核。这里验证的是板上状态与发送数据，实际光色以灯带目视结果为准。

复核入口：上位机目录运行 `python tests/check_led_ui.py --url http://127.0.0.1:8765 --prefix led_console_exe`。此脚本会实际切换灯效并在结束后恢复默认自动播放，始终不使能电机。证据文件位于本目录的 `led_console*.json/png` 与 `ws2812_console_hardware.json`。
