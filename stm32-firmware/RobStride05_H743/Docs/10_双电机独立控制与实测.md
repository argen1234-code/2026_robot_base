## 日常使用

1. 双击上位机目录里的 `RobStrideConsole.exe`，选择探针并连接；连接前退出 Keil Debug。连接核对板上全部 Flash 与 AXF，不自动使能。
2. MCU 每次重启后，展开“首次接入”，勾选两台已分别设置为 127、126 并接回，点击“核对两台身份并开放独立控制”。现在 ID 已分配好，直接核对即可；核对要求两个新鲜身份、在线反馈、UID 不同，固件不会凭 CAN ACK 判定两台在线。
3. 点击电机 1 或电机 2 卡片，分别设置限制、勾选固定空载确认，按“准备 → 使能 → 运行”。准备/使能始终零目标。每台参数、兼容确认、运行目标、状态、故障、回执各自独立；切换卡片不会撤销另一台已运行的速度。
4. 控制区“减速停止 / 选中电机失能”仅控制选中电机。顶部“两台全部失能”或 Esc 对两台同时撤销目标，并分别尽力发送停止帧；看两台反馈确认完成。断开、退出也请求两台失能。
5. 曲线、测量和通信诊断跟随选中电机；CSV 每行带 `motor`（1/2）和 `motor_id`。页面上方始终同时显示两台状态与实测/目标速度。

每台默认准备参数仍为 33 rad/s、2.4 A、20 rad/s²；软件命令硬上限仍为 ±33 rad/s、11 A、150 rad/s²。实际物理验证仅覆盖下表的空载工况，不能把范围上限视为已实测性能。

## OLED

八行固定显示：运行时长/上下文切换、堆余量、M1 的 ID/状态/实测速度、M1 目标、M2 的 ID/状态/实测速度、M2 目标、两行 RTOS 线程统计。最后两行每秒轮换 MOTOR/OLED 与 HEALTH/LED，保留原任务统计。离线速度显示 OFFLINE；两台始终同时可见。

屏幕上的速度是 rad/s；DIS=失能，PRE=准备好，ENA=使能，RUN=运行，STP=减速，FLT=故障，CFG=准备中，ENG=使能中。

## 保护与当前边界

每台分别维护状态机、速度斜坡、参数读回、反馈离线/故障/超速保护；同一个 MOTOR 任务串行推进两套上下文。CAN TX 有明确归属，另一台不会轮询/取消本台发送。共享总线故障、服务长间断和全停会撤销对应双机授权/目标；不会自动恢复运动。当前是两台独立速度控制，没有小车的线速度、角速度或左右轮联动逻辑。

两台实物均拒绝通信超时参数，`timeout_motor_supported=0`。仍需在界面单独确认兼容提示。不能承诺拔 CAN 或 MCU 停止时电机自动停机；保留可直接切断电源的手段。RUN 仍然锁存，关闭浏览器标签页不会停止。

CAN 模块上的 120Ω 跳帽是终端电阻；整个总线仅保留两个物理端点终端。实测当前通信无错误，但本次未用万用表测量断电总线阻值。
