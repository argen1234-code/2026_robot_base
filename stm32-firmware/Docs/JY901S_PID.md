# JY901S 绝对角度与双轮速度控制

更新日期：2026-11-03。对应本目录的 `RobStride05_H743` 和 `上位机/RobStrideConsole.exe`。

## 接线

沿用参考工程 `D:\竞赛\2026嵌赛\multi-function_car\h7_lvgl_rtos_base` 的 USART6、PG9/PG14、9600 8N1 配置。

| H743 引脚 | 连接 | 用途 |
|---|---|---|
| PG9 / USART6_RX | JY901S TX | 接收角度、角速度 |
| PG14 / USART6_TX | JY901S RX | 串口发送引脚，当前读取模式不主动修改模块寄存器 |
| 3.3V | JY901S VCC | 与参考工程一致 |
| GND | JY901S GND | 共地 |
| PB9 / FDCAN1_TX | CAN 收发器 TXD | 保持现有电机 CAN 接法 |
| PB8 / FDCAN1_RX | CAN 收发器 RXD | 保持现有电机 CAN 接法 |

两台 RS05 继续接同一 CAN 总线的 CANH/CANL。轮速反馈来自电机 CAN 报文，**不需要额外 PWM 或编码器引脚**。

模块需按参考工程使用 9600 波特率的标准 0x55 协议，输出 0x52 角速度帧、0x53 欧拉角帧。驱动检查 11 字节帧校验和，不发送校准、保存、清零等模块指令。

## 坐标与方向

车头朝前，从车顶往下看：

- 左轮：电机 2，ID 126；原始电机速度负值对应车轮前进。
- 右轮：电机 1，ID 127；原始电机速度正值对应车轮前进。
- 底盘面板中的左右轮目标、实测速度、误差、实测 Iq 都采用车辆坐标：前进为正。原有独立电机面板仍显示电机原始坐标。
- 正角度为向左、逆时针；负角度为向右、顺时针。通常将 JY901S Z 轴朝上；如果安装反向，可修改面板中的航向方向。
- 左右轮分配和正反转共用 WASD 面板中的设置。进入 WASD 时，该设置也写到固件底盘配置，避免显示坐标与实际控制坐标不一致。

| 动作 | 左轮车辆速度 | 右轮车辆速度 | 电机 1 / ID 127 原始速度 | 电机 2 / ID 126 原始速度 |
|---|---:|---:|---:|---:|
| W 前进 | + | + | + | - |
| S 后退 | - | - | - | + |
| A 左转 / 正角度转向 | - | + | + | + |
| D 右转 / 负角度转向 | + | - | - | - |

## 角度含义

MCU 本次上电后收到的**首个有效航向**设为 0°，之后连续累计跨越 ±180° 的角度。不是磁北零度，也不是每次运行重新清零。

- 输入 90°：转到相对上电姿态左转 90°的位置并保持。
- 输入 0°：回到上电姿态。
- 输入 -90°：转到相对上电姿态右转 90°的位置并保持。
- 输入 360°：从零位累计转完整一圈；不会自动折算成 0°。
- “当前位置设为 0°”是用户显式更改参考零点，停止底盘控制后使用。

## 控制结构

绝对角度 PID → 左右轮目标速度 → CAN 0x700A → RS05 速度模式（mode=2）的内部速度闭环。

H743 不再计算左右轮速度 PID，不再发送 0x7006 电流目标。双轮速度控制直接使用同一套电机速度模式。

控制周期约 20 ms。JY901S 按模块自身输出频率更新，不将 50 Hz 控制周期宣称为传感器更新率。

- 角度误差直接为 `目标角度 - 累计航向`。角度环 D 项使用 JY901S Z 轴角速度，正输出产生左轮后退、右轮前进。
- 角度 PID 输出为差速轮速 rad/s；左右轮速度与 Iq 均读取电机 CAN 反馈，Iq 为 0x701A 实测值。
- 复用已有速度上限、电流限制和加速度斜坡。角度 PID 使用输出限幅与积分抗饱和。
- 停止/退出后速度目标归零，通过原有减速斜坡发送给电机；全部失能继续使用原有停止接口。
- 航向控制、双轮速度、WASD、独立电机控制统一使用速度模式。

## 上位机使用

1. 下载同目录的新固件，打开新 `上位机/RobStrideConsole.exe`，连接设备，等待“双电机已就绪”。身份核对、速度模式准备和零速使能自动完成。
2. 打开“电机控制”下的“JY901S · 绝对角度 / 双轮速度控制”。确认显示 JY901S 在线，手动左转车体时航向增加。
3. 需要修改速度上限、相电流或加速度时，在断开状态分别选择两张电机卡片设置，再连接应用。默认 33 rad/s、2.4 A、20 rad/s²。
4. 调速度：填写左右轮目标，点击“运行双轮速度”。调角度：填写绝对目标角度，点击“转到目标角度并保持”。二者自动选择相应控制方式。
5. 运行中修改航向 Kp/Ki/Kd，点击“实时应用航向 PID 参数”。可切换角度、左轮速度、右轮速度、左右实测电流曲线；CSV 同时包含当前配置和观测量。
6. “停止底盘控制”将双轮速度目标归零；原有“全部失能”与 Esc 继续可用。WASD 在连接就绪后可直接使用。失能或清错后重新连接即可再次自动就绪。

新参数保存在本次固件运行的 RAM 中；断电回到代码初值。初始角度环 `0.04 / 0 / 0.005`，角度控制的差速轮速限幅 2 rad/s；这些是供开始调试的参数，不是实车整定结果。

## 实现与复现

- `App/app_chassis.c`：航向 PID、双轮速度目标、配置命令、统一车辆坐标、观测发布。
- `App/app_pid.c`：位置式 PID。
- `Devices/jy901s.c`：流式帧解析、软件零位和连续角度。
- `BSP/bsp_jy901s.c`：USART6 引脚、中断接收环形缓冲。9600 下不需要额外 DMA。
- `App/app_debug.h`：在旧结构末尾追加 `chassis_cmd` / `chassis`，不改变旧成员偏移。
- 上位机通过当前 AXF/DWARF 生成地址、字段布局与 Flash 校验，不复用旧地址。
- `Tools/integrate.py`、`Tools/cubemx_baseline` 和 `.ioc` 同步了 UART 配置；HAL UART 文件取自本机与当前 HAL 版本一致的 STM32Cube H7 V1.13.0。
