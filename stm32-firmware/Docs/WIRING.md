以下信号引脚已按当前固件源码核对。开发板排针位置按实物 PA/PB/PG 丝印寻找；旧商家资料与本板封装存在差异，本表不套用未确认的连接器针号。供电以各模块实物型号和丝印为准，断电接线。

## 2. 电源与地线总表

| 模块 | 电源正极 / VCC | 地线 / 负极 | 说明 |
|---|---|---|---|
| H743 开发板 | 板卡规定的 5V 输入或其指定供电接口 | 板上 GND | 使用板上稳压得到 3.3V；多电源同时接入前核对板卡供电隔离方式 |
| VP230 / SN65HVD230 类 CAN 模块 | 板上 3.3V → 模块 3V3 / VCC | 模块 GND → 板上 GND | 当前使用的是 3.3V 收发器 |
| JDY31 裸模块 | 3.3V → VCC | GND → 板上 GND | 若是带稳压底板的版本，按底板标注选择输入；UART 信号使用 3.3V 电平 |
| JY901S | 3.3V → VCC | GND → 板上 GND | 沿用本工程参考接法 |
| SSD1306 OLED | 3.3V → VCC | GND → 板上 GND | 本表针对支持 3.3V 的 I²C 模块；SCL/SDA 上拉到 3.3V |
| WS2812 灯带 | 稳定的灯带电源 → VCC / 5V，常见为 5V | 灯带 GND / 电源负极与板上 GND 共地 | 电源电压按灯带型号；供电能力按灯数和亮度选，不从 MCU GPIO 供电 |
| 右轮 RS05，ID127 | 独立电机电源正极 → 电机 V+ | 电机 V− → 电源负极 | 电压按电机铭牌/手册和现用电源核对 |
| 左轮 RS05，ID126 | 同一电机电源另一路正极 → 电机 V+ | 电机 V− → 电源负极 | 两台并联供电，各自独立电源支路；大电流不经过开发板 |
| CAN 信号参考地 | — | 电机 CAN 信号地（若有独立端子）与 CAN 模块、H743 GND 相连 | 当前收发器不隔离；按电机端口定义建立共地，不把 CANH/CANL 当作 GND |

电机电源、板卡电源和灯带电源可以来自不同稳压支路。各支路建立公共信号地；电机和灯带的负载电流分别回到各自电源负极，避免通过细信号地线回流。

WS2812 的 PA6 数据为 3.3V 电平。若实物 5V 灯带的数据高电平门限不兼容 3.3V，在 PA6 与 DIN 之间使用适合 800 kHz 单向数据的 3.3V→5V 电平转换，例如 5V 供电的 74AHCT125。最后一颗灯珠的 DOUT 不用接回主控。

## 3. 两台电机 CAN 接法

| 网络 | 应连接的端子 |
|---|---|
| CANH | CAN 模块 CANH、右轮 ID127 的 CAN_H、左轮 ID126 的 CAN_H |
| CANL | CAN 模块 CANL、右轮 ID127 的 CAN_L、左轮 ID126 的 CAN_L |
| 信号参考地 | H743 GND、CAN 模块 GND、两台电机按其接口定义接出的信号参考地 |
| 电机电源正极 | 电源 V+ 分别接两台电机 V+ |
| 电机电源负极 | 电源 V− 分别接两台电机 V− |

实物布线采用一条主干，各节点短支线，CANH/CANL 用双绞线。
**整条总线仅在两个物理末端各接一个 120Ω 终端电阻**；不要按“每个模块一只”安装。
CAN 模块跳帽与电机内部已有终端都要计入总数。全部断电后测 CANH–CANL，正常两只 120Ω 并联时约为 60Ω；实物其它电路可能影响读数。

当前默认轮子安装映射：左轮为电机 2 / ID126，负速度前进；右轮为电机 1 / ID127，正速度前进。
这是软件映射，不通过交换电源正负极改变转向。

## 4. 电脑和手机连接

| 使用方式 | 连接路径 | 是否需要 SWD 探针 |
|---|---|---|
| 原电脑完整上位机（电机、曲线、CSV、灯效、JY901S 等） | 电脑 USB → 调试器 → H743 SWD | 需要；若用无线 DAP，则按探针自身连接方式 |
| 电脑蓝牙遥控 | 电脑蓝牙 → JDY31 → PA9/PA10；Windows 配对后选择出站 COM 口 | 不需要 |
| 手机蓝牙遥控 | 手机蓝牙 SPP → JDY31 → PA9/PA10 | 不需要 |

蓝牙 UART 两端 TX/RX 交叉；CAN 收发器与 MCU 的 TX/RX 同名相接。
PA9/PA10 即便位于板上“下载座”，也属于 USART1 蓝牙信号；SWD 使用 PA13/PA14。
JDY31 的 STATE、EN/KEY 等其它引脚不在当前固件控制范围内，按该模块正常透传工作的硬件要求处理。
