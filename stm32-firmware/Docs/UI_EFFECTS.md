# 模板新增视效移植与回归

日期：2026-11-01。目标仓库：MacSwimmm/2026-AIC，修改前提交 `3af57daa8195a49abe5fc9be86aa44882dd0d027`。模板参考：MacSwimmm/upper-computer-template，提交 `71f6c076b7723165c5e875ad8a2ecdb82b27a908`。

## 移植内容

- 保留首页、五模块轮播、设置抽屉、键盘/触摸导航和响应式布局，补齐模板新增的黑绿功能区主题。
- 功能区标题、测量卡、诊断卡、实时曲线、日志、关节读数、灯带状态与指南使用模板同一套 15×15 位移网格。鼠标方向和速度驱动局部切片，按时间阻尼恢复；页底新增 RobStride 绿色字标并共享采样引擎。
- 首屏点阵使用模板的 OffscreenCanvas Worker；不支持或 Worker 加载失败时回退主线程。关闭点阵立即清空画布，离屏与隐藏时暂停。
- 功能区与页底分别提供开关，立即生效、本机持久化，纳入“恢复默认外观”。强调色继续由原设置控制。
- 保留模板连续跨卡片、实时数据交换缓存、80 ms 缓存延迟回退、最多六个活动效果/八百万活动像素/十六份缓存等行为。

## 业务兼容与适配

以现有 `app.js`、`led.js` 的 DOM、事件、数据和状态门禁为准，不引入模板演示后端、仿真数据、任务模块或示例配置。两份业务脚本、`bridge.py`、`profile.py`、固件全部保持本轮基线字节。`server.py` 只增加五个静态资源白名单，原 API、CSP、令牌与控制队列不变。

模板通过克隆 DOM 缓存功能区；本项目的曲线由 Canvas 绘制，单纯克隆会丢失曲线。因此复制缓存时将曲线像素转为内存图片，监听 Canvas 尺寸重设来刷新快照。快照保留祖先样式上下文，适配原有测量卡和设置抽屉。跳过轮询重复写入相同文本产生的无效变化，诊断卡被轮询整体替换时继续迁移扰动状态。数据变化后缓存准备超过 80 ms 会显示实时原生界面。

效果图层不接收指针事件；按钮、输入、标签、下拉框、首次配置折叠入口、焦点和拖动操作恢复原生界面。Esc 仍执行原两台全部失能请求。故障、失能和危险按钮的语义颜色保持原有行为。系统减少动态效果、触摸、失焦、页面隐藏与离屏均沿用静态或暂停策略。

单文件 EXE 重新生成，内置静态资源与源码同步。`firmware_profile.json` 仍由仓库内原 AXF 提取，固件 ABI 与 Flash 身份不变。
