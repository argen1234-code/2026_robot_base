# JDY31 蓝牙遥控（2026-11-04）

修改的是 `D:\竞赛\2026 AIC\2026-AIC`。手机和电脑共用下面的串口文本协议。
手机应用由使用者选择；电脑功能集成在本仓库 `上位机/RobStrideConsole.exe` 的
“电机控制 → JDY31 · 蓝牙遥控”中。蓝牙遥控可以独立于 SWD 使用。

## 接线与参数

| JDY31 信号 | STM32H743 接线 |
|---|---|
| TXD | PA10 / USART1_RX |
| RXD | PA9 / USART1_TX |
| GND | 板上 GND，共地 |
| VCC | 按模块/底板标注供电；裸模块与带稳压底板的供电要求可能不同 |

MCU 串口为 **9600，8 数据位，1 停止位，无校验、无流控**；信号为 3.3 V 电平。
参考工程 `h7_lvgl_rtos_base/Drivers/User/Src/usart.c` 的 USART1 实际配置是 9600，
其 `PCB_Pinout.md` 写的 115200 与源码不一致，这里以源码为准。
若现有 JDY31 被改过 UART 波特率，需要将模块与 `App/app_config.h` 的
`APP_BT_BAUD` 设为一致。本次不会自动发送 AT 指令或修改模块持久设置。

JY901S 仍使用 USART6 / PG9 RX、PG14 TX，9600；CAN、OLED、PA6 灯带及双 Cache 关闭配置保留。

## 手机先这样用

1. 下载本次 HEX/AXF，并让 H7 正常运行。电机保持 ID 127、126 的原有接线。
2. 手机连接 JDY31 的经典蓝牙 SPP，选择**文本发送**，每条启用 **CRLF / 回车换行**。
3. 发送 `@PING`，收到 `PONG RS05-BT/1` 表示已经收到 H7 的协议回复。
4. 发送 `@SPEED=1`，设置行驶/转向轮速为 1 rad/s。
5. 发送 `@ARM`。可能先收到 `PENDING ARM`；等到 `OK ARM` 后才能行驶。
   ARM 会核对两台电机的身份和反馈，并沿用原状态机完成准备、参数读回和零速使能。
   等待身份或参数时最多 4 秒；失败会撤销遥控并失能两轮。ARM 本身不会给出非零轮速。
6. 按住前进时**每 150–200 ms 重复发送 `@F`**；松开时立即发送 `@S`。
7. 结束使用发送 `@!`，使两轮失能。

上面的每条文本都要带真实 CRLF。下文写 `@F\r\n` 时，`\r\n` 是两个结束符
（十六进制 `0D 0A`），不是发送反斜杠和字母。`@F` 的完整字节是 `40 46 0D 0A`。
大小写均可；不支持没有 `@` 的裸字母或只有 LF 的行结尾。

## 指令对照

| 完整指令表示 | 效果 |
|---|---|
| `@PING\r\n` | 返回 `PONG RS05-BT/1`，检查 H7 协议通路 |
| `@STATUS\r\n` | 返回使能、准备阶段、运动标志、设定轮速、结果码和两台实测轮速 |
| `@ARM\r\n` | 接管蓝牙遥控，准备并零速使能两轮；等待 `OK ARM` |
| `@SPEED=1\r\n` | 停车时将方向指令使用的轮速设为 1 rad/s；允许 0–33；行驶中修改返回忙 |
| `@F\r\n` | 两轮前进 |
| `@B\r\n` | 两轮后退 |
| `@L\r\n` 或 `@Q\r\n` | 原地向左转 |
| `@R\r\n` 或 `@E\r\n` | 原地向右转 |
| `@FL\r\n` | 前进左弯：左轮零速，右轮前进 |
| `@FR\r\n` | 前进右弯：左轮前进，右轮零速 |
| `@BL\r\n` | 倒车并向左改变车头方向：左轮后退，右轮零速 |
| `@BR\r\n` | 倒车并向右改变车头方向：左轮零速，右轮后退 |
| `@S\r\n` 或 `@STOP\r\n` | 两轮目标归零，使用原加速度减速；蓝牙正常使能后仍保持使能 |
| `@!\r\n` 或 `@DISARM\r\n` 或 `@RELEASE\r\n` | 两轮失能，取消准备/运动，清除待处理遥控；之后重新 ARM |
| `@H\r\n` | 已使能时续发当前方向；超时后不能靠 H 恢复，必须重新 ARM |
| `@~\r\n` 或 `@RESUME\r\n` | ARM 的别名；只恢复零速使能，不恢复旧方向 |
| `@LIMIT=33,2.4,20\r\n` | 蓝牙未使能时设置下一次准备的速度上限、电流上限、加速度 |
| `@MAP=1,-1,1\r\n` | 蓝牙未使能时设置左轮槽位、左轮前进符号、右轮前进符号 |

LIMIT 三项分别允许 `(0,33] rad/s`、`(0,11] A`、`(0,150] rad/s²`，默认 33、2.4、20。
需要重新应用 LIMIT 时先 `@!`，再 LIMIT，最后 ARM。已由 SWD 准备/使能且未处于运动模式的
两台电机可通过 ARM 零速接管，仍使用当时已准备的限值。

MAP 的槽位为 0（电机 1 / ID127）或 1（电机 2 / ID126），符号为 ±1。
默认 `1,-1,1`：左轮 ID126，前进负转；右轮 ID127，前进正转，与现有 WASD 一致。
例如轮速为 1 时，F 发给电机 1/2 的目标分别为 `+1/-1`；L 为 `+1/+1`；R 为 `-1/-1`。
这是按当前安装映射计算的目标，实际车辆转向仍需上车核对。

参考工程原本重复按同一方向会切换开/关。本工程改为**重复方向保持同一方向并续时**，
便于手机/电脑按住发送；停车使用 S，避免续发时反复开关。两轮差速不能横向平移，
因此参考工程 L/R 的横移意图在这里映射为原地左右转。GPS、路况、航点指令没有移植。

## 回执与超时

- `OK ...`：该操作已接受。`PENDING ARM` 只表示准备中；`OK ARM` 才表示准备和使能完成。
- `STATE armed=1 phase=0 moving=1 speed=1.000 result=0 v1=... v2=...`：状态快照。
  v1/v2 单位 rad/s，保留各电机原始正负号。`armed=1` 表示蓝牙控制授权有效。
- `ERR 2`：参数/轮速超出范围（包括某轮准备的速度上限）。超限不截断后继续行驶。
- `ERR 3`：状态不允许，一般需要重新 ARM。
- `ERR 5`：电机离线或 UART 收到了错误/溢出。
- `ERR 7 / 8 / 10 / 11`：参数读回失败 / 电机故障 / CAN Bus-off / 电机保护。
- `ERR 9`：600 ms 没有有效运动续发，已将两轮目标归零并撤销蓝牙控制授权。
- `ERR 17`：其它控制模式占用，或当前动作不允许修改设置。
- `ERR 1`：未知指令、帧过长或格式错误。

只有成功的方向命令或 H 会续运动期限；PING、STATUS、垃圾数据、重复 ARM 都不能续运动。
超时后按原加速度归零，之后必须重新 ARM。串口接收出错同样撤销遥控；单轮故障则失能整对。
连接本身、ARM、读状态和换参数都不会自动恢复旧运动。

普通 STOP 是目标归零，不是瞬间机械刹停。MCU 任务和 CAN 正常工作是该保护生效的前提；
原电机侧 CAN 超时参数仍可能不被电机支持，不能据此声称 MCU 停机时车辆一定自停。

## 电脑端

1. Windows 蓝牙设置配对 JDY31，在“更多蓝牙设置 → COM 端口”找到**出站**端口。
   手机和电脑通常不能同时占用同一 JDY31 的 SPP 连接；切换时先断开另一端。
2. 打开同目录新版 `上位机/RobStrideConsole.exe`，展开“JDY31 · 蓝牙遥控”。
   选择端口并连接。必须收到 H7 的 PONG 回执后才显示连接成功；打开 COM 口本身不算成功。
3. 设置轮速、限值和安装映射，点击“使能蓝牙遥控”，等到“已使能”。
4. 按住方向按钮行驶，松开归零；或点击“开启蓝牙 WASD”后用 W/S 前后、A/D 原地左右转。
   组合键 WA/WD/SA/SD 对应 FL/FR/BL/BR。Space 归零，Esc 两轮失能。
5. 修改行驶轮速后点击“停止并应用轮速”；修改准备限值/映射时先“两轮失能”。
6. 收发窗口显示实际串口指令和固件回执；页面同时显示 M1/M2 实测轮速。

电脑后台约每 180 ms 续发；页面约每 180 ms 更新按键授权，页面 650 ms 没有更新就停车。
H7 另有独立 600 ms 运动超时。窗口失焦、编辑输入框、切换模块、折叠面板会停车并退出蓝牙键盘；
关闭页面/断开蓝牙/退出正常后台会尝试两轮失能，异常断链由 H7 运动超时处理。

SWD 原界面、双电机独立控制、WASD、JY901S、灯效与 CSV 保留。蓝牙已接管时，SWD
准备/使能/运行、WASD 或航向运动请求会被拒绝，避免两个来源同时改轮速。
任一来源的停止/失能仍可撤销运动。切回 SWD 时先在蓝牙面板失能，再连接/重新准备使能。
电脑蓝牙页不通过 SWD 读完整遥测，只显示本协议提供的遥控状态和两轮速度；原完整遥测仍由 SWD 页提供。
