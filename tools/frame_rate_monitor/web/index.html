采用最近 5 秒的滑动窗口，每秒更新。刚连接时需要几秒形成稳定读数。彩色与深度统计的是本地图像消息频率；人体识别统计每次完成的结果，画面中没有人也计数。

“电脑预览输出”是树莓派发送预览副本的频率，浏览器实际渲染还可能受网络和电脑性能影响。它不会替代本地帧率。

在 Foxglove 里查看同一组数字
  1. 添加“数值 / Gauge”或“绘图 / Plot”面板。
  2. 本地彩色：/performance/fps/local_color.data
  3. 本地深度：/performance/fps/local_depth.data
  4. 人体识别：/performance/fps/person_detection.data

以上话题每秒发一次统计数值；应读取 data 字段，不要把统计话题自身的 1 Hz 当作相机帧率。
